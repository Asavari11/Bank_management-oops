# Bank Management App (Java Swing)

A simple Bank Management System built using Java, OOP concepts, and Swing GUI.
This application allows users to create accounts, log in, deposit/withdraw money, transfer funds, and view transaction history.  
It also includes an Admin Dashboard to manage all accounts and transactions.

---

## Features

### User Functions
- Create new bank account  
- Login using Account Number / Username + PIN  
- Deposit and withdraw money  
- Transfer funds to another account  
- View personal transaction history  
- Auto-updated balance view  
- PIN validation  

### Admin Functions
- View all customer accounts  
- View all transactions  
- Delete any account  
- Direct admin access  

---

## Tech Stack
- Java (OOP)
- Java Swing (GUI)
- CardLayout for screen transitions

---

## How to Run
1. Clone the repository  
2. Open the project in any Java IDE (IntelliJ, Eclipse, NetBeans)  
3. Ensure all `.java` files (Bank, Account, Transaction, BankManagementApp) are in the same package  
4. Run `BankManagementApp.java`  
5. The app starts with the Login Page
